# Contributing to Hermes Pro Max

Thank you for your interest in contributing to Hermes Pro Max.

Hermes Pro Max is an open-source, integration-first AI agent platform. Contributions that improve reliability, interoperability, security, documentation and the overall architecture are welcome.

## Ways to Contribute

You can contribute through:

- Bug reports
- Feature proposals
- Documentation improvements
- Security improvements
- Model-provider integrations
- Agent and tool integrations
- Routing and fallback improvements
- Memory and RAG improvements
- Tests and benchmarks
- Deployment improvements
- Code reviews
- Architecture proposals

## Development Principles

Contributions should follow these principles:

1. Prefer mature open-source integrations over unnecessary reimplementation.
2. Keep components modular and replaceable.
3. Avoid vendor lock-in whenever possible.
4. Never commit API keys, passwords, tokens or private credentials.
5. Prefer reproducible implementations with automated tests.
6. Document important architectural decisions.
7. Keep the free and open-source core functional independently.
8. Evaluate security and privacy implications before introducing new integrations.

## Issues

Before opening a new issue:

- Check whether a similar issue already exists.
- Describe the problem clearly.
- Include reproduction steps when applicable.
- Include relevant logs without exposing credentials or personal information.
- Describe the expected behavior.

## Pull Requests

Pull requests should:

- Address one clearly defined objective.
- Include an explanation of the change.
- Avoid unrelated modifications.
- Include or update tests when appropriate.
- Update documentation when behavior changes.
- Pass existing validation and test workflows.

Large architectural changes should preferably be discussed through an issue before implementation.

## Security

Do not publicly report vulnerabilities that could expose users, credentials or infrastructure.

Please follow the instructions in `SECURITY.md` for responsible vulnerability reporting.

## Licensing

By contributing to Hermes Pro Max, you agree that your contributions may be distributed under the project's Apache License 2.0.

## Code of Conduct

Contributors are expected to communicate professionally and collaborate constructively.

Technical disagreement is welcome. Personal attacks, harassment and abusive conduct are not.
